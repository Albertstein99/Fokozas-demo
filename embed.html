The lightweight viewer

Give your page
a moving figure.

Use the viewer component for lessons, articles, and collections. Keep the editor separate: a figure needs only the shared viewer JavaScript and WebAssembly files.

A minimal embed

Copy the viewer/ folder from the homepage bundle alongside your page. Load its script once, then add as many components as you need.

<script src="viewer/fokozas-widget.js" defer></script>

<fokozas-viewport
  example="centroid"
  label="The medians of a triangle"
  style="--fokozas-height: 360px">
</fokozas-viewport>

Available examples: demo, centroid, circumcenter, orthocenter, euler, nine-point, and thales. Each instance has its own construction and camera state. This version embeds these predefined scenes; importing an arbitrary saved editor scene is not implemented yet.

A borderless figure

Add borderless to remove the header, border, and shadow. Drag, wheel/pinch zoom, and keyboard navigation still work. The canvas follows the surrounding page’s solid background.

<fokozas-viewport borderless example="centroid"
  label="The medians of a triangle"></fokozas-viewport>

Figures inherit the page’s CSS color-scheme and react to changes to ancestor classes, styles, or data-theme. Set the theme on your page; individual figures have no theme selector.

One runtime, independent figures

The component shares its renderer across the page, renders visible figures in small batches, and releases offscreen pixel buffers. WebGL2 is preferred, with a Canvas 2D compatibility fallback. There is no continuously running animation when a figure is idle.

Host it anywhere static files work

Serve the complete homepage folder, retaining its relative paths. It works at the domain root or under a repository subpath on GitHub Pages. The downloadable standalone viewer also works offline without a server.
